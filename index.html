Autopost

Autopost is a private, single-user tool made by Akim Goncharov, a video maker based in China. It uploads videos that Akim has produced himself to his own channels: the personal YouTube channel “Akim Goncharov” and the “Scholarshipers” YouTube channel, which he runs.

The tool runs only on Akim's own computer. It is not offered to the public and does not access any other person's account or data.

It uses the YouTube Data API to upload videos and set their title, description, tags, thumbnail and publishing time. By using this tool you agree to be bound by the YouTube Terms of Service.
