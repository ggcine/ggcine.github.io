Autopost Privacy Policy

Last updated: October 27, 2026

Autopost is a private tool used only by its developer, Akim Goncharov, to publish his own videos to YouTube channels he owns or manages. It uses YouTube API Services.

What data the tool accesses

  • Permission to upload videos and thumbnails to the signed-in YouTube channel (youtube.upload).
  • Read-only access to the signed-in channel's basic information, such as its name and ID, to confirm which channel is connected (youtube.readonly).

The tool does not read comments, subscribers, analytics, messages or any data of other users.

How the data is used and stored

The access tokens issued by Google are stored only on the developer's own computer and are used only to upload videos and read the channel name. No data is sent to any server other than Google's. Nothing is sold, shared with third parties, or used for advertising.

How to revoke access and delete data

Access can be revoked at any time on the Google security settings page. Deleting the local token files removes all stored data. Autopost stores no other YouTube data; any data obtained from YouTube API Services is deleted within 30 days after access is revoked.

Google and YouTube policies

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
